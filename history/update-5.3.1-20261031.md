## 🚀 주요 변경 사항

### 1. AI 로스팅 가이드 모드 목표 예열 도달 ~ 배출 완료 단축키 및 포커스 정상화
- **목표 예열 도달 시점부터 배출 완료까지 단축키 완전 보장**:
  - 로스터기가 설정한 목표 예열 온도에 최초 도달한 시점(`hasReachedTargetPreheat`)부터 생두 투입, 원두 배출을 거쳐 최종 종료 전까지 메인 앱의 기본 포커스를 유지하고 모든 단축키가 즉시 인식되도록 개선했습니다.
  - 예열 완료 후 생두 투입 대기 중 온도가 1℃ 미만으로 일시적으로 내려가더라도 목표 예열 도달 상태가 취소되지 않고 유지되어 단축키 및 자동 포커스 복귀 정책이 중단 없이 지속됩니다.
- **생두 투입 단축키(Space, S) 인식 오류 해결**:
  - 생두 투입 전 메인 화면의 입력 필드(생두 이름, 생두 용량, 목표 예열온도 등)에 포커스가 머물러 있을 때 단축키가 무시되던 문제를 수정했습니다.
  - 목표 예열 도달 이후에는 메모 등 텍스트 편집 모달을 제외하고 활성 입력 필드를 자동으로 해제(`blur`)하여 Space 또는 S키 입력 시 생두 투입 확인 및 이벤트가 100% 정상 작동합니다.
  - 생두 투입 확인 모달 및 배출/종료 확인 모달 닫힘 시 AI 가이드 창으로 포커스가 넘어가던 로직을 제거하여 기본 포커스를 메인 앱에 유지합니다.

### 2. 1차 팝 접근 및 발생 시 단축키(1키) 무반응 현상 원천 차단
- **AI 입력창 포커스 간섭 방지 및 단축키 릴레이 강화**:
  - 1차 팝 접근 알림(`pop1_approaching`) 이벤트가 AI 웹뷰로 전송된 후 AI 프롬프트 입력창(ChatGPT 입력창 등)에 포커스가 머물러 있을 때, 단축키 `1`을 누르면 타이핑 중으로 오인되어 릴레이가 차단되던 버그를 해결했습니다.
  - AI 가이드 창 내부에서 입력창이 비어있거나 1차/2차 팝 단축키(`1`, `2`)를 누른 경우 즉시 로스팅 단축키로 인식하여 메인 앱으로 릴레이를 전달하고, 입력창을 `blur` 처리한 후 메인 윈도우로 포커스를 복원합니다.
  - 메인 윈도우 단축키 핸들러에서도 1차 팝 단축키 입력 시 활성 필드를 자동 해제하여 즉각 반응하도록 보장합니다.

### 3. AI 로스팅 가이드 창 클릭 후 3초 무동작 시 메인 앱 자동 포커스 복귀 구현
- **3초 비활성 타이머 정책 일관성 확보**:
  - 목표 예열 온도 도달 시점부터 배출 완료까지, 사용자가 AI 로스팅 가이드 창(BrowserView 웹 화면 또는 툴바 등)을 마우스로 클릭하거나 조작한 후 아무런 동작을 하지 않으면 3초 뒤 자동으로 메인 앱(`mainWindow`)으로 포커스가 이동합니다.
  - 투입/배출 확인 모달이 열려 있을 때 3초 타이머가 비활성화되던 문제를 개선하여, 모달 상태에서 AI 창을 클릭하더라도 3초 뒤 메인 모달로 자동 복귀하여 단축키로 승인할 수 있도록 했습니다.
  - 메인 프로세스에서 메인 윈도우 포커스 복귀 시 `show()`, `focus()`, `moveTop()`, `webContents.focus()` 및 AI 창 활성 엘리먼트 `blur()`를 확실하게 실행하여 단축키가 지체 없이 즉시 입력되도록 처리했습니다.
