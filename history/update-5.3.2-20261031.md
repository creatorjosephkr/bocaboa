## 🚀 주요 변경 사항

### 1. AI 로스팅 가이드 모드 로그아웃 확인 창(Confirm Modal) 추가 및 웹뷰 가림 현상 해결
- **실수 방지를 위한 로그아웃 확인 팝업 추가**:
  - AI 가이드 창 브라우저 바의 **로그아웃** 버튼 클릭 시 즉시 세션이 초기화되지 않고, 사용자가 실수로 누르는 상황을 방지하기 위한 확인 창(`confirm-popup-overlay`)을 표시합니다.
  - "로그아웃하시겠습니까? 로그인 정보 및 캐시 데이터가 삭제됩니다." 안내 문구와 함께 `취소` 및 위험 액션 스타일의 `로그아웃` 버튼을 제공합니다.
  - `Escape` 키 입력 또는 팝업 배경 클릭 시 확인 창이 즉시 닫히며, 확인 창이 열려 있는 동안에는 로스팅 단축키 및 스페이스바 입력이 메인 창으로 오전달되지 않도록 차단합니다.
- **macOS BrowserView 네이티브 레이어 가림 현상 해결**:
  - macOS Electron 환경에서 `BrowserView`가 항상 HTML DOM보다 상위의 네이티브 뷰 레이어(NSView)로 렌더링되어 확인 모달을 가리던 문제를 해결했습니다.
  - 모달 표시 시 `aiWebViewWindow.setBrowserView(null)`을 호출하여 윈도우에서 네이티브 레이어를 완전히 분리하고, 닫힐 때 원래 위치(`y: 120`)로 즉시 재연결합니다.
  - BrowserView 분리 시 화면이 하얗게 비는 깜빡임을 없애기 위해 현재 웹뷰 화면을 캡처하여 배경 스냅샷(`snapshotImg`)으로 부드럽게 유지합니다.

### 2. 구글 계정 로그인 및 텍스트 입력창 타이핑 보호 (대문자 S 단축키 오동작 해결)
- **대문자 S(Shift + S) 입력 시 단축키 오인식 및 포커스 해제 버그 원천 해결**:
  - 구글 로그인 페이지(`accounts.google.com`) 등의 입력창이 비어 있는 상태에서 대문자 `S`를 입력할 때, 조합키 검사 누락으로 인해 투입 단축키(`s`)로 인식되어 글자 입력이 차단(`preventDefault`)되고 입력창 포커스가 풀리며(`blur`) 메인 창으로 튕기던 치명적인 현상을 해결했습니다.
  - `Shift`, `Ctrl`, `Cmd`, `Alt` 조합키 입력 시에는 로스팅 단축키 릴레이에서 완전히 제외하여 `Shift + S`, `Shift + Q` 등 대문자 및 기호 입력이 브라우저에 그대로 전달되도록 보장했습니다.
- **인증 도메인 및 폼 입력 필드 전면 보호**:
  - `accounts.google.com`, `auth0.com`, `appleid.apple.com` 등 계정 인증 페이지이거나 `email`, `password`, `search`, `tel`, `url` 타입의 폼 입력 필드에서는 단축키 릴레이가 일체 동작하지 않도록 안전장치를 구축했습니다.
- **일반 텍스트 입력창 타이핑 보장 및 1차/2차 팝 단축키 안전 한정**:
  - 사용자가 입력창에 포커스를 둔 상태에서는 첫 글자가 소문자 `s`, `q`, `e`이더라도 로스팅 단축키로 가로채지 않고 정상적인 글자 입력으로 처리합니다.
  - ChatGPT 프롬프트 입력창이 비어 있는 상태에서 단독 숫자 `1` 또는 `2`를 누른 경우(1차/2차 팝 기록 목적)에 한하여 안전하게 단축키가 릴레이되도록 정책을 정밀화했습니다.
