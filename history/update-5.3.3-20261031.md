## 🚀 주요 변경 사항

### 1. 1차 팝 및 2차 팝 확인 모달(5초 자동 확정) 도입
- **원두 배출과 동일한 5초 자동 승인 팝업 구현**:
  - 로스팅 진행 중 1차 팝 또는 2차 팝 버튼(단축키 `1`, `2`)을 누르면 즉시 확정되지 않고 확인 창(`pop1-confirm-modal`, `pop2-confirm-modal`)이 화면에 표시됩니다.
  - 사용자가 취소하지 않고 가만히 두면 5초 카운트다운 후 최초 버튼을 누른 시점의 시간과 온도로 자동 확정되어 그래프 왜곡 없이 팝 이벤트가 기록됩니다.
  - 확인 모달이 열려 있는 상태에서 단축키(`1` 또는 `2`, `Space`, `Enter`)를 한 번 더 누르면 즉시 확정되고, `ESC` 키 또는 취소 버튼을 누르면 팝 이벤트가 취소(롤백)됩니다.
  - 모달 드래그 이동 및 최상단 z-index 레이어 적용으로 조작 편의성을 확보했습니다.

### 2. 로스팅 상세기록 화면 배출량 입력 시 포커스 해제 및 숫자 1 입력 불가 버그 해결
- **결과 모달 및 텍스트 편집 모달의 단축키 간섭 원천 차단**:
  - 로스팅 종료 후 상세기록 화면(`report-modal`)에서 배출량(로스팅 후 중량, `input-modal-weight-roasted`) 입력 필드에 숫자 `1`을 입력할 때, 포커스가 강제로 풀리며(`blur`) 1차 팝 단축키로 오작동하던 문제를 완벽히 해결했습니다.
  - 단축키 핸들러(`handleShortcut`), 메인 창 포커스 복원 이벤트(`onMainFocusActive`), 단축키 릴레이(`onAiShortcutRelay`)의 텍스트 편집 모달 보호 목록에 `report-modal` 및 활성 모달 카드 내부의 모든 입력 필드를 포함시켜, 배출량 및 메모 등에서 모든 숫자와 단축키 알파벳이 온전히 입력되도록 보장했습니다.
