## 🚀 주요 변경 사항

### 1. 히터 단계별 소비전력 측정/등록 관리 시스템 (사이버 테마 모달) 신설
- **4종 사이버 게이지 실시간 모니터링**:
  - **소비전력 (POWER)**: 0 ~ 600W 범위 게이지, 실시간 측정 와트(W) 및 앱 고정 와트 비교 표시
  - **실시간 전압 (VOLTAGE)**: 0 ~ 300V 범위 게이지, 실시간 교류 전압(V) 모니터링
  - **실시간 전류 (CURRENT)**: 0 ~ 10A 범위 게이지, 전력과 전압 기반 실시간 암페어(A) 자동 환산
  - **보카보카 온도 (TEMP)**: 0 ~ 250°C 범위 게이지, 드럼 내부 실시간 온도 및 고온(>240°C) 경고 표기
- **실시간 전압/전력 연속 스트림 전광판 (`cyber-power-stream-canvas`)**:
  - HTML5 캔버스 기반으로 우측에서 좌측으로 부드럽게 흐르는 2줄(윗줄: 전압 / 아랫줄: 전력) 실시간 수치 스트림 및 좌우 페이드 그라데이션 효과를 탑재했습니다.
- **13개 화력 단계별(6.0단 ~ 12.0단) 소비전력 매핑 및 개별 관리 테이블**:
  - 6.0단부터 12.0단까지 0.5단 단위 총 13개 화력 단계의 앱 고정 소비전력, 실시간 측정 전력, 전압, 전류, 측정 일시를 한눈에 관리할 수 있는 전용 테이블을 제공합니다.
  - **개별 등록**: 실시간 측정된 전력값을 해당 화력 단계의 앱 고정 소비전력으로 즉시 등록
  - **수동(수기) 입력 모달 (`cyber-manual-power-modal`)**: 소비전력(W) 직접 수기 입력 및 ±10W, ±50W 퀵 조절, 기본 전압(220.0V) 및 전류 자동 대입
  - **수정 및 초기화**: 단계별 개별 수정 및 공장 기본값(`default_power_map.json`)으로의 전체 초기화 지원
- **전단계 연속 측정 및 등록 반자동 모달 (`cyber-sweep-guide-modal`)**:
  - 6.0단부터 12.0단까지 화면 안내에 따라 화력을 맞추고 단계별로 소비전력을 순차 측정/등록할 수 있는 가이드 모달을 제공합니다.
- **측정 결과 JSON 저장 및 GitHub 연동**:
  - 측정 결과를 로컬 PC에 JSON 파일로 저장 및 불러오기 지원
  - GitHub 공용 저장소(`bocaboa-profile`) 및 개인 저장소로 측정 데이터를 직접 내보내고 동기화할 수 있는 드롭다운 메뉴 탑재

### 2. 스마트기기 (Tuya Wi-Fi 스마트 플러그 & BLE) 연동 및 전력 제어 고도화
- **Tuya Wi-Fi 스마트 플러그 실시간 연동**:
  - Tuya Open Cloud API(Region, Client ID, Secret, Device ID) 기반 실시간 소비전력/전압 데이터 수집 및 주기적 폴링 지원
  - 스마트기기 관리 창에서 등록된 전력측정기 전원 원클릭 ON / OFF 원격 제어
  - 기기 정보 수정 모달(`tuya-device-edit-modal`) 및 실시간 연결 테스트 기능 탑재
  - 기기 설정 정보 JSON 파일 내보내기 및 불러오기 지원
- **안전 자동 전원 차단 옵션 연동**:
  - 로스팅 중 과열 발생 시 스마트 플러그 전원 자동 차단(`autoCutoffOnOverheat`)
  - 원두 배출 시 전원 자동 차단(`autoCutoffOnEject`) 연동

### 3. 산지별 생두 목록 선택 및 관리 시스템 (Green Bean Selector & Coffee Belt)
- **세계 커피 벨트 135종 생두 탐색**:
  - 중남미, 아프리카, 아시아, 디카페인 대분류 탭 및 국가/산지별 세부 필터링 탭 제공
  - 실시간 생두 명칭 검색 필터 지원
- **세계 커피벨트 지도 (World Coffee Belt Map) 라이트박스 뷰어**:
  - 고해상도 커피벨트 지도 이미지 미리보기 카드 제공
  - 클릭 시 대형 전체화면 라이트박스 팝업(`coffee-belt-lightbox-modal`)으로 지도 확대 열람 가능
- **사용자 커스텀 생두 등록 및 기존 생두 정보 편집**:
  - 신규 생두 항목 인라인 추가 폼 (`form-add-custom-bean`) 제공
  - 산지, 권역, 품종(Variety), 가공방식(Processing) 상세 정보 수정 모달 (`edit-green-bean-modal`) 지원
  - 기본 제공 생두 수정 시 '사용자 등록' 목록에 새로운 커스텀 생두로 안전하게 분리 저장
